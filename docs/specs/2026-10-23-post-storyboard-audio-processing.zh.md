# 分镜后的显式音频后处理

日期：2026-10-23。所属阶段：Audio Quality V1，SFX 暂停；不新增顶层路线。

## 制作流程

生成原音 → 试听并采用 → 生成并确定分镜 → 点击「生成后处理」 → 试听、下载处理结果或导出视频包。

候选、完整原音及已采用原音的试听直接读取原始文件，不因播放而临时执行空间渲染。顶部「生成分镜」右侧常驻「生成后处理」，仅对当前短句或整段工作区操作。

## 规划与处理

- 采用当前剧情、角色、台词和完整有效分镜，包含无对白镜头的动作上下文。人声原音已采用、分镜齐备后，一次整批调用既有外部文案 API 规划逐句声音起点、落点和移动；不向模型发送音频，不调用 TTS 或 ASR。
- 声音位置以角色相对听者的物理位置为依据。没有动作时保持静止；上句落点承接下句起点，明确场景转换或中间无对白动作已完成位置变化时可重新定位，景别变化本身不改变距离。空镜仅参与空间动作衔接，不伪造人声音频。
- 后处理用实际原音时长推进动作，不按工程估时或段后等待计算路线。移动从规划的实际起点开始，避免每句「靠近」都跳回远处。处理继续复用现有 D 空间算法，保留原音；不引入 FFmpeg 或新环境。
- 逐段处理、显示进度并支持取消。规划先保存，成功结果逐段保存，单段失败不清除其他结果；相同输入重试复用规划和已有成品。完成后现有距离、移动参数可继续手调，下次显式处理使用修改后的设置。

## 保存、播放与导出

原音资产保持不变。处理结果是独立文件，并记录源资产、实际源文件哈希、规划、设置、渲染器及输出哈希；工程 JSON 和两个工作区保存对应元数据。输入或设置改变时提示结果需要更新，保留旧文件。

处理结果试听只读取保存好的文件；完整处理结果可按脚本顺序拼接试听和下载。音频包始终保留原音，并仅附已有有效处理结果；视频包与混音在整批处理结果完整有效时使用成品，否则沿用原音，避免混用半批结果。导出不隐式调用 AI 或空间渲染。ComfyUI 工作流继续直接使用导出音频，不另行替换音轨。

## 验收

验证原音试听没有空间请求、按钮位置与前置条件、跨句端点衔接、手动设置及工作区保存、取消和晚到结果、失败后恢复、源文件保持、实际 CPU 渲染、结果播放与导出字节一致。逐段卷积只保证规划声位衔接，不将它描述为所有房间尾声和速度已经物理无缝。真实 API、CPU 媒体和网页部署以实际收据为准。
