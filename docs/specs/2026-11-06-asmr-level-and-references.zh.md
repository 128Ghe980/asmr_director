# 连续 ASMR 动作的响度和双音频参考

已采用的人声以它完成后处理时的电平进入成片。前景触发声与人声应当都能听清，触发声可根据表演稍响或稍轻。同一动作从无台词段延续到台词段时，前后几次接触应听起来属于同一场表演。安静环境维持背景音量。

- 无台词段 X 的原生主视频是下一段独立音效的音色参考。接续台词段 X+1 使用两路独立 H3 参考，Audio 1 提供台词、口型和停顿，Audio 2 提供已处理的触发声、手部接触和释放时机。成片只混合这两条音轨一次。
- 普通与增强合片对已标记接续的 X 使用相同的空间和响度处理，参照 X+1 的已采用台词。X+1 比较前段末尾与本段开头的有效发声，考虑用户对两段增益的相对调整。测不到可用的接触声时回到段级目标。整段共用一个增益，保留耳间差异和停顿。峰值余量不足时限制音效。
- 响度参数是实现的可调默认值。当前前景的中性目标为 −32 LUFS，按本段已采用的人声允许向两侧调整。极低本底、静音、源电平及峰值保护可以限制实际电平。边界测量和真人听感分别验收。
- 输入素材可复用。使用旧的 64 秒候选升级时，只需重新生成第 3、6、9 段接续主画面和两条合片。已安装的 ComfyUI 音效节点也须更新，完整操作见批跑包中的说明。
