# 短句表示语义台词单元

日期：2026-10-23。Audio Quality V1 继续进行，SFX 暂停。本定义覆盖此前把短句等同于完整语法句的说明。

「短句」相对于一篇文案切成几大段，是较短的语气、意思或动作台词单元。一个单元可以含多个句号、问号或其他标点；例如「回来啦。我还没睡，就猜你快到了。」可以完整保留在同一单元。

模型按语义、动作、情绪与自然衔接生成 units。既有简洁篇幅建议用于指导写作，不由句号数量重新划分合法单元。现代 groups[].units 与兼容 flat sections 回复都保留模型合法边界，程序只映射导演属性、顺序标识和停顿；既有真实能力上限及严格字段校验保持。显式旧稿整理工具的规则行为保持，不能自动套用到生成、采用或编辑流程。

采用策划时一条 section 对应一个工程片段，两工作区使用相同源单元。普通短句编辑、失焦、载入与切页均不按句界重拆；撤下拆短句提醒及整批按句界拆分入口。用户选区拆分与合并仍按用户指令执行，不迁移或猜测合并已保存工程。

整段页编辑在单个源单元内时保持原 ID 和分段；跨源单元改写时，仅把受影响范围作为一个用户编辑单元，保留前后未改单位。文字不按标点或长度猜测新语义边界，两页同步及编辑撤回继续保护各自资产。整段生成的容量分组可以在完整源单元之间重新打包（既有 500 字符／32 项），但不切开单元。手工输入的单个超能力长单元原文保留，由既有生成校验说明能力限制。

TTS 内部按标点处理停顿或上下文窗口，不等于拆改工程台词。识别和音频切分继续服务于这些用户采用的台词单元，不由语法句定义替换目标。
