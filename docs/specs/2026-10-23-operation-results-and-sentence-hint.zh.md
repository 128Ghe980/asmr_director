# 操作结果与多句提示

日期：2026-10-23。路线：Audio Quality V1；父阶段继续进行，SFX 暂停。

左侧文案卡片的批量生成、整批校对和音频后处理结果统一显示为单行摘要。点击「查看结果」打开独立原生模态窗口；不自动弹出，不将完整结果放进文案列表上方。批次进度和取消按钮继续在原处显示。

窗口完整保留失败镜号、台词和错误、校对改动与说明、应用/撤回以及后处理逐镜和整体试听下载。摘要的省略仅用于显示，不截断明细或改写工程数据。校对零修订只显示「校对完成：无修订」，不表示内容质量获得认证。窗口只有一个内容滚动区域，长文字换行；支持关闭按钮、Esc、背景点击和返回触发按钮焦点。关闭会清理后处理试听请求及临时播放资源，不取消主生成任务；切换工程或短句/整段工作区会关闭窗口。

后续用户纠正后，已完全撤下「还有长段未拆成短句」／「有台词包含多句，可按需拆分」提醒及按句界拆段入口。短句指较短的语气、意思或动作台词单元，可以包含多个句号；不以完整语法句为必要边界。详见[当前语义台词单元定义](2026-10-23-semantic-speech-units.zh.md)。

生成和采用保留模型合法语义单元；普通编辑、失焦和切页不再按句号重拆。手动选区拆分、合并与两页同步及撤回保留；已有项目不自动迁移或猜测合并。

验证范围是组件交互、集成流程、类型、lint、构建及实际服务静态资源身份。没有读取或修改用户浏览器工程，也不将 JSDOM 的 dialog 测试替身称为真实浏览器焦点、背景隔离或视觉验收。
