# 分镜剧情上下文与整批校对

日期：2026-10-23。所属路线：Audio Quality V1；父阶段继续进行，SFX 暂停。

## 目标

雪夜归家历史包中，逐镜分镜反复站在门口、等待接衣、递茶后继续持杯，且全部中近景。改善分镜 API 的生成输入和动作编排，再用一次整批文本校对补齐跨镜关系；不把校对变为后续操作的门槛。

## 生成

给文字模型完整脚本顺序、当前镜头位置、相邻语义和实际音频时长。其他未采用音频的台词也可作剧情上下文，不要求先生成全部音频。工程起点、段后等待和估计时长不决定动作路线。场景背景仍是生成上下文，不整段重复进最终 H3 prompt。

连续镜头继承角色、道具和已发生动作的状态，允许同场景自然移动、落座与镜头跟随。每镜围绕一个主要事件，写清当前状态、可见动作与结束结果，允许合理静止；区别说话者动作、邀请听者做的动作、过去事实、未来计划及条件句。脸嘴在说话时可见，关键手部与道具也应入画，不固定所有镜头为中近景。保持引用角色外貌、不新增人物身份、原台词和原音、镜头模式、实测时长与原有简洁字段结构。

增加上下文只影响新生成输入和进行中请求保护，不自动使历史整批分镜过期。生成期间剧情上下文变化时取消或丢弃晚到结果。

插入无对白镜头时只创建可编辑单元，不调用文字 API。默认说明为「待设计：根据前后剧情安排自然衔接的无对白画面。」，不预设道具、位置或动作。生成分镜时，待设计或泛化衔接要求由已有全稿、当前位置和前后文落实为具体画面及自然环境底噪；占位文字不是已发生的剧情。用户明确填写的画面意图继续优先保留。默认值修改仅影响之后新增，不迁移或覆盖旧描述。

生成和校对的文字接收上限统一复用工程保存边界：visual 800、action 600、camera 400 字符；title 120、ambientSound 600 字符。320/180/120 仅为提示词中的简洁写作建议，超过建议长度不拒绝，不截断、不重写、不自动修复或重试。必填文字仍须非空，未知字段和来源 metadata 仍禁止由模型修改。

## 整批校对

批量分镜生成完成后，若当前分镜齐备，向现有外部文本 API 发一次整批请求。全稿与全部分镜是上下文，只有本轮成功且没有被手改的镜头允许自动修订。检查道具归属和交接、人物及听者位置、动作重复重启、结束状态、时长可行性及关键对象的可见性。未来、条件和回忆不要求当前表演；不强制增加动作或变化景别。

API 只返回必要的文字修订及简短原因。仅修改标题、画面、动作、机位和空镜环境声描述；台词、音源、时长、顺序、独立/连续偏好与素材绑定由代码保留。应用时同步重绑原本有效的下游前镜引用，保留其文字，不复活原来过期的镜头。

文字模型使用按原稿连续排列的三位镜号，服务端再映回工程片段 ID，避免旧 ID 跳号导致错绑。模型仅返回有变化的文字字段，服务器合并其余原字段；缺少修订或空对象的无改条目忽略，实际修订仍原子校验编号、权限、字段和长度。画面描述对应开镜状态，动作写事件及结束状态，交接后的下一镜应从该结果承接。独立镜头可开镜已经坐好，不强补走路或坐下过程。

已有项目通过批量更多操作中的「整批校对」手动调用；先展示修订预览，用户点击「应用修订」才修改，避免静默覆盖历史手改。自动修订后同样显示摘要并可撤回。校对结果和撤回记录仅在当前页面内存中存在，应用后的分镜照常保存进工程和相应短句/整段工作区。

校对只执行一轮，不评分、不要求通过、不循环重审；失败或取消保留生成结果，后处理和导出继续使用已有规则。用户可重新调用手动校对。工程、工作区或相关输入变化时丢弃晚到结果和过期预览。应用与撤回均先保存，再更新页面；撤回只还原校对的分镜改动，不回滚无关音频、混音或后处理设置。

## 验证

覆盖 API 输入中的完整剧情、动作规则、独立/连续及空镜语义，单镜和批次晚响应保护，整批一次调用、自动/手动修改范围、手改保护、失败和取消、保存失败、工作区隔离、下游引用重绑及撤回。用历史雪夜归家包的只读副本运行真实文本 API，核对修订前后和不变量；原包、生产音频、浏览器工程、远端视频生成结果不作为测试写入目标。真实视频是否执行提示词仍需成片对照，文本校对不作该项认证。
