# Short speech means semantic dialogue units

Date: 2026-10-23. Audio Quality V1 remains in progress; SFX remains paused. This definition supersedes descriptions equating a short unit with one grammatical sentence.

“Short” contrasts with dividing a complete script into a few large passages. A unit follows delivery, meaning or an action and can contain several sentence endings. A greeting followed by closely related reassurance can remain one unit despite containing multiple periods.

The model creates units using meaning, action, emotion and natural transitions. Existing brevity guidance does not authorize punctuation-based regrouping of valid output. Modern groups[].units and compatible flat sections preserve valid model boundaries; code maps direction, sequential identifiers and pauses. Existing actual capacity bounds and strict field validation remain. The explicit legacy-draft organization tool retains its rule-based behavior and must not run automatically during generation, adoption or editing.

Adoption maps each section to one project clip and shared source unit in both speech workspaces. Editing, blur, loading and workspace switching do not split grammatical sentences. Remove the unsplit-sentence reminder and batch punctuation-splitting control. Explicit user selection splits and merges remain available. Do not migrate or guess how to merge previously saved clips.

A paragraph edit within one source unit preserves its ID and boundary. An edit spanning units replaces only that affected range with one user-edited unit, keeping unaffected surrounding units. Do not infer new semantic boundaries from punctuation or length. Cross-workspace source synchronization and undo retain their asset protection. Paragraph-generation capacity packing may regroup complete units under existing 500-character/32-item bounds, but cannot split a source unit. A manually entered oversized single unit remains intact and is subject to existing generation capacity checks.

TTS clause parsing for pauses or forward context does not redefine project units. Recognition and audio cutting continue serving the adopted dialogue units instead of substituting grammatical-sentence boundaries.
