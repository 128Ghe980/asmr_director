# 独立ASMR制作与用途响度平衡

本轮属于Audio Quality V1。用户要求先发布旧版，再改善独立声音的同质化、缺乏ASMR感和段间音量不均；不将新增文字约束视作真实音质验收。

- 主表演保持原模板，包括空手对镜。独立取音视频明确ASMR放松助眠用途，以一种主材质、真实接触、可见细微形变和可辨音色/起落构成；材质与触发节奏来自当前动作，不随机插入道具。邻段比较音色、接触方式和节奏，避免同一soft/dry/friction换词重复。无呼吸、人声或音乐。
- `asmrSound.role`可选`trigger|ambience`。新规划明确输出，旧缺省保留旧prompt和混音方式。trigger采用材料近录；ambience使用安静环境，不套强制手部接触模板。校对与逐块编辑不得无意丢失role。
- 显式role启用`balanced-v1`，旧缺省逐样本兼容。主要触发声按空间化后的实测响度做有限、整段一致的增益补偿；台词伴随声参考该段人声水平。环境底声只减弱、不提升原本安静的来源。保留停顿、瞬态、左右比例与声位，限制最终真峰值。
- gainDb在新模式映射为受控微调：trigger的−12为中性、ambience的−30为中性，微调范围−6至+6 dB，ambience最多+3；界面显示相对微调。旧模式gainDb含义不变。目标电平为初始产品策略，需要真实素材试听校准，不保证所有材质听感相同。
- 新节点`AsmrDirectorBalancedSpatialAudio`明确区分能力，缺少时提示安装更新，不能静默用旧节点冒充平衡成功。运行器中role和策略身份仅影响增强合片缓存；manifest中prompt与时长保持时，只改用途/响度设置不重跑H3。网页给旧声音选择新用途会同时使用对应的新版取音prompt包装，重新导出后该音效因prompt改变而重新生成；不能宣称所有用途切换都只重合片。保留原版、旧输出和所有恢复状态。
- 复用现有D引擎、ComfyUI、Python依赖与SOFA；不修改共享人声D处理，不新增常驻服务。提供完整节点更新包，保持旧工程文件不被自动重写。

验收包含prompt分用途与多样性、真实DP少量生成检查、role在编辑/校对/ZIP/runner中保持、不同幅度来源的响度收敛、安静/近静音不被抬高、动态与峰值、旧缓存兼容及新包禁网dry-run。H3最终听感需目标机生成试听；无实际成片时不得称音质已验收。
