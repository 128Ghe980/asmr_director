# 批跑器横屏与竖屏

日期：2026-10-29。范围：Audio Quality V1 内的既有 ComfyUI 批跑器。

用户可以在批跑窗口的“生成画幅”选择“竖屏 9:16”“横屏 16:9”或“按项目 / 原设置”。窗口实际启动批次时按工程记忆选择，dry-run 不保存偏好。命令行新增 `--aspect-ratio portrait|landscape|workflow`：不传时读取包内可选 `aspectRatio`；明确传 `workflow` 时覆盖包默认，恢复旧运行规则。

若 MiniMax 节点的宽高直接连接同一个 `ResolutionSelector` 的 0/1 输出，选择横竖预设时修改该节点的 `aspect_ratio`，保持 `megapixels` 与 `multiple`。标准参考模板没有该节点，使用 672×1216 / 1216×672；这是按 32 倍数对齐的近似比例。模板原文件不改写。

旧包缺省保持以前的宽高、工作流和任务指纹。明确预设与高级 `--width/--height` 不能同时指定，自定义尺寸应加 `--aspect-ratio workflow`。画幅同时影响主视频和 ASMR 触发音视频；指纹记录实际有效尺寸/节点配置，改比例生成相应新结果，切回可恢复已有结果与两种合片。未确认远端任务仍先对账，不重复提交。

此改动不增加模型或节点依赖，不改声音处理、剧情、候选数量和默认种子。新增包可声明 `"aspectRatio": "portrait"` 作为默认；网页导出继续动态读取当前运行器文件，不要求重启网页服务。
