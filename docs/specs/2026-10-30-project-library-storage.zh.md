# 项目库容量与持久保存

2026-10-30；当前 Audio Quality V1 的保存可靠性修复，不新增顶层路线。

## 问题

万圣节新工程 JSON 导入后，当前页面能显示39段，但状态为“本地保存不可用”。用户刷新或重开后可能看不到新工程。既有同步载入还将“读出旧库后回写失败”误当为“无法读取”，可能退回示例工程。

## 合同

- 支持既有本地项目库和旧单工程迁移；保留全部项目、合法历史修订、采用记录与短句/整段工作区。
- 使用 IndexedDB 保存完整项目库，原 localStorage 数据保留为迁移来源；不靠删除旧项目或裁切数据解决容量。
- 保存成功以数据库事务提交为准；失败不得显示“本地已保存”。按顺序保存，旧异步结果不得覆盖新工程或将较新未保存状态标为已保存。
- 首次加载在恢复完成前不得启动自动保存，读出旧数据不因回写失败丢失。避免用空库或示例覆盖尚未恢复的用户库。
- 数据库不可用时仅在能保证一致性的条件下使用旧存储；若无法持久保存，当前编辑仍可见并显示失败。
- 不更改工程 JSON、生成内容、音频或批跑包格式；不执行模型或视频生成。

## 验收

迁移、完整往返、配额/事务失败、异步写入次序、过期保存状态与重载恢复需有测试。用户实际页面导入新工程后，应显示20条采用语音、19无台词、20后处理并且刷新后仍在项目列表；旧项目仍存在。部署采用活动发布副本的隔离构建，仅叠加此次变更。
