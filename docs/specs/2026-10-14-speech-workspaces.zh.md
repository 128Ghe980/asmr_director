# 独立短句与整段语音工作区

日期：2026-10-14（HKT）。所属固定路线：**人声导演与真实 ASMR 音效质量 V1**，仍进行中。本契约描述既有阶段内的一项实现，不新增顶层路线关卡。[English version](2026-10-14-speech-workspaces.en.md)。

## 产品契约

编辑器提供「短句」和「整段」两个独立工作区。两边共享台词，生成结果各自保留。切换标签只恢复对应工作区，不切句、重新分组、重新生成、放弃或采用音频。

采用 AI 创意文案时同时初始化两套工作区。旧工程没有工作区元数据时，默认进入短句区并保留已有采用音频；新建整段区使用相同台词 ID，生成结果为空。短句区继续保留原有 `clip` 与 `long_text` 流程。

短句区逐句显示和编辑真正的自然句子。采用 AI 创意时先按句号、问号、叹号、分号及换行切分原文，再同时创建两套工作区；保留标点、引号、空白与小数，不机械按逗号或字数切词。整段区把这些相同 ID 的短句显示成完整段落，生成后也以它们为切分目标。初始按完整短句累加到约 **80 个汉字**，这是已测文案、参考与引擎组合下的暂定偏好，不是通用模型上限。段落成员会保存，切换标签不会重新分组。

旧工程保持原文与原结果，含多句的长条目会显示「切短句」。用户操作前保存两套结果的完整工程修订；切分同步两页、保留每套库各自的临时时段和末尾等待，不按文案比例裁音频。完整旧录音不能挂为第一条新短句的有效素材，相关新短句从待生成开始，原素材及候选文件保留在历史与录音记录中。普通单句改词仍保留各页旧素材并标记待更新。

时间线默认折叠为标题栏，点击「展开时间线 / 收起时间线」切换；折叠会释放编辑空间，切换语音分页不重置本次展开状态。

## 持久状态与当前视图

`AsmrProject.speechWorkspace` 为兼容旧工程而设为可选，包含：

| 字段 | 契约 |
| --- | --- |
| `version` | `1` |
| `activeMode` | `short` 或 `paragraph` |
| `short`、`paragraph` | 两套独立结果库 |
| `groups` | 有序 `{ id, clipIds }` 段落定义 |

每套结果库保存人声片段、总时长、辅助轨道、情绪曲线、混音设置、可选分镜计划、导出结果与可选混音指纹。工程顶层时间线、分镜计划与导出字段表示当前工作区。切换、保存或为后台操作取另一工作区视图前，先保存当前工作区快照。

整段分组依据工作区 `groups` 与当前投影时间线，不使用 `speech_group_id`、破坏性 `prepareParagraphGroups` 或全局生成方式切换。重复、缺失或无对白成员不能建立有效的生成语境。

人声设置分别保存短句与整段偏好。选择参考声音、异步参考导入完成时，应更新操作开始时的工作区；短句设置不能被整段设置覆盖。运行任务、候选与请求控制器不写入持久工程 JSON。

## 共享文案与独立结果

文案修改在两套结果库间同步台词、表达元数据、对白/无对白类型、顺序、插入与删除。生成结果仍属于各自工作区。保持句界的改词保留现有音频并标记 `audio_stale`；结构切分或合句时，旧完整录音由受保护修订保留，不能冒充新句子的有效结果。

修改一个短句源文，会使该短句结果和所属整段结果过时；其他短句与其他整段保留结果。对白顺序或成员变更应使受影响的整段来源身份失效。插入无对白镜头时，若对白内容与顺序不变，可继续保留原对白音频，但仍需重新判断时间安排与混音是否有效。

撤回文案编辑只恢复共享源文，保留两套结果库最新的生成结果，不能用旧的非当前工作区快照覆盖后来采用的音频。已删除 ID 可恢复所属工作区的历史音频；仍存在且源文改变的 ID 保留当前音频并标记相应过时状态。撤回候选采用也只作用于对应工作区，保留另一套结果。

试听、已采用音频预览、波形分析、下载、混音与分镜音频绑定使用当前结果库。切回另一标签恢复它自己的结果。旧混音导出可保留供比较，同时由指纹指出需要重新混音。

## 整段生成与严格切分

整段请求使用 `generationMode: "paragraph"`；工程有工作区元数据时，请求必须使用整段区投影。服务器按保存的成员连接原文，**只生成当前 A 一次**，不增加后文 B/C、中性补句或原生音质自动重试。

当前整段输入契约最多为 500 个 UTF-16 单元和 32 个目标短句，在 TTS 前检查。严格切分器接受不超过 120 秒的原生 48 kHz、单声道 PCM16 WAV。这些是实现边界，与暂定的约 80 汉字段长偏好分开。

整段配方使用选定的固定参考、在参考文本模式下保留自然参考文字，以及 `maxSteps: 800`。原生 CFG 2、temperature 1、timesteps 10、GPU layers 0、low-VRAM 沿用已验证配方。`ASMR_VOXCPM2_PARAGRAPH_CLI_PATH` 可只为该模式选择修正解码器。参考文本模式仍取决于所选声音是否有可用参考原文。

原有 `clip`、`long_text` 分支继续使用 profile 执行文件、参考文字规范化方式、最高 600 的自适应步数以及既有生成行为。新模式不替换这些分支，也不改它们的原生命令参数。

分析前先保存完整原生 WAV。离线检查器逐个核对剩余原音开头的目标短句及全部剩余文案。每个非末尾切点都必须经过既有严格左右独立识别与实际安静区间检查，由 `requireTwoSided: true` 强制执行；整段切分不调用可选语义 API 回退。既有文字、时间戳与静音阈值不放宽。

整段请求额外启用 `allowShortSentenceParticle`：仅对 3–9 个汉字、前至少两字逐字一致、明确自然句末的一处「啦／了」差异使用专门 `sentence_particle` 证据。保留真实文字分数（例如三字句为 2/3），不伪造 95% 拼音分数或降低其他差异的全局阈值。必须在完整 ASR 字词边界定位，后文起始严格匹配；非末尾仍须真实安静区间及独立左右识别，末尾须核对完整剩余原音及独立最终识别。原 `clip / long_text` 不启用此短句定位选项，既有长句拼音规则保持。

独立左侧识别仅缺最后一个轻声「啦/了」、其余字及词级文本完全一致时，可以仅对同一切点的分析输入安全修剪边缘静音，整次切点搜索最多额外识别一次。无足够安全静音则跳过。复查仍须识别完整目标并继续通过右侧和最终检查，不能接受缺字；不改原 PCM、切点或 ASR 参数。

识别对照读取整段的逐句证据；第一句源识别为整段原音，后续为剩余原音，不能将每句目标冒充整段目标。失败时保存所属短句 ID、识别检查点及诊断；历史失败日志可从完整录音接口恢复展示。整段「重新识别」仅读取该候选绑定的完整原音，按当前共享短句重新检查并新增候选，不调用 TTS、不改变原候选或自动采用。原音格式/时长、工程/分页/全部成员与文案、容量和发布前原候选状态都须验证；清单锁内再次检查源候选，全部通过后原子发布。

切分器仅使用分析证据，直接裁取**原始 PCM 字节**，不把检查器修剪、淡化后的试裁音频作为最终素材。所有短片连续覆盖原音第 0 帧至最后一帧，保留自然停顿与两端声音；不做响度归一、调速、调音高、交叉淡化或额外插入音频静音。

全部短句与切点通过后才发布短句素材和同组候选，候选以一次原子 manifest 写入保存。每个成员记录相同的整段、全文、完整原音素材以及有序短句素材和范围。若不能确认全部切点，保留完整原音，不发布部分短句裁片，并禁止把完整原音当作短句采用。

## 候选与异步操作的范围

`candidate.provenance.generationMode` 区分结果库：`paragraph` 属于整段区，`clip` 与 `long_text` 属于短句区。同一台词 ID 可同时拥有两套候选。

每个工程、片段、工作区分别限制 12 个未采用候选。候选与完整录音列表接受 `workspaceMode`，录音分页游标也绑定该范围。放弃一个整段候选时，按工程、组 ID、完整原音素材原子放弃全部成员；所有 WAV 与短句区候选保留。

整段来源指纹覆盖完整有序成员的台词与表达字段。任何同组短句改文都会使该整段全部候选过时。采用前重新读取服务器状态并核对当前来源，在一次工作区修订中采用全部通过检查的短句，另一结果库不变。

后台生成、混音与分镜任务记录启动工作区。完成时取该工作区投影，检查当前源文或混音指纹，再把结果只合并到对应结果库。候选状态请求尚未完成时切页，不能把采用操作转向刚显示的结果库；切工程、切会话和改文继续执行原有过期响应保护。参考导入绑定启动工作区；切换模式取消正在进行的候选重检。

## 无对白镜头

`kind: "silent"` 台词槽代表没有对白的镜头，支持编辑画面描述和时长，保留分镜生成功能。它不要求语音素材，不进入 TTS 或整段成员，也不计入人声候选与已采用人声下载要求。无对白槽分隔段落；插入与时长变化同步到两边，各自的画面结果继续独立保存。

**自然源文句界映射已实现。** 局部词语修改保留真正单句的 ID 与边界；旧多句条目编辑后会成为实际短句。两页改文即时同步。短句页在本条编辑结束失焦时确认新增句界，避免打字过程中切走焦点；整段页编辑直接按受影响区域的自然句末映射。逐字保留全文、标点、引号和空白，按顺序复用已有 ID；缩短的重写合并单元，不切开词语。例如把“先坐一会儿。我给你倒茶。”替换为“雨停了。”会得到一个短句。

重写后超过 32 个成员或 500 字符生成限制时，只在受影响组内按完整单元划分新增组，即使短句 ID 未变也遵守分组限额；其他组成员保持不变。不会为凑字符上限切开单句，生成入口仍核对硬限制。改词保留各页已有素材并按需标记过时；结构切分的旧完整录音由受保护修订保留，相关新句子结果待生成。结构撤回恢复两页原时段及末尾等待，并保留后来独立采用的音频。实现见 [speech-workspace.ts](../../apps/web/src/lib/asmr/speech-workspace.ts)，证据见 [原回归](../../apps/web/src/lib/asmr/speech-workspace.test.ts) 与 [逐句及历史恢复回归](../../apps/web/src/lib/asmr/speech-workspace.short-sentences.test.ts)。
