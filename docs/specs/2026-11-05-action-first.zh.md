# 无台词原生 ASMR 与边做边说试验

本合同属于 Audio Quality V1。用户在先声音后画面的试跑中反馈音画不贴合，要求改试从无台词主视频取得声音，再引导下一段边做边说。英文版见 [English](2026-11-05-action-first.en.md)。

## 表演与用户流程

创意、审核脚本、采用人声、设计画面与声音、后处理、导出批跑的顺序保持。新创意可以在一段无台词持续触发之后，让下一段继续相同操作并说话，不强迫所有声音操作在段尾收手，也不让所有台词都只静止说话。取放、递交、拆开等已经完成的一次性动作不得重复；持续敲击、摩擦等才适合延续。单次动作不超过 10 秒，单段生成不超过 15 秒。

声音设计用可选 `asmrSound.continuation: "previous-silent"` 标记实际接续。它只用于紧接无台词段的有台词触发段，两段应有相同、仍在进行的动作。仅仅相邻或手位相同不足以构成接续。界面可以查看或取消标记；旧工程不按相邻关系自动推断。画面是否独立起镜仍遵循原有设置和最多两次末帧接续规则，声音关联不强制镜头关联。

视频导出增加独立模式「动作声音接续（试验）」，包字段 `silentAudioMode: "action-first"`。原方式与上一版 `asmr-first` 保留可选，不迁移已有工程或改写已采用音频。

## 生成依赖

1. 所有无台词段直接生成主视频及其原生声音，不再为该段另生成独立音效视频。提示词强调助眠 ASMR、具体材质、轻柔接触、动作节奏与安静间隙。无实物模板继续约束画面为空手模拟，声音描述不得把虚构目标实体化。
2. 被标记的台词段，先读取紧前无台词主视频中同候选的音轨，作为本段独立音效视频的声音参考。参考用于保持材质与发声方式；生成的是符合本段时长和动作的新声音，不把上一段整条音轨原样重复。
3. 本段独立音效经现有 D 空间与响度处理后，与原有台词 WAV 混合。混合结果同时进入 H3 音频参考和主视频最终声音。嘴部只跟随台词，手部跟随触发动作。
4. 未标记的台词段沿用原有台词主视频与独立音效流程。

导出用 `asmrSound.referenceShotId` 指向紧前无台词生成任务；如果前段有连续块，指向其最后一块。无台词源音频不得跨候选借用，失败、缺失、过期或被修改时，依赖段明确等待恢复，不退回其他音源。

## 后处理、合片与恢复

普通合片保留各主视频已有声音：无台词为原生声，接续台词为已经混好的声音。增强合片对无台词原生声做一次 D 并替换；已经预混的接续台词不得再次叠音或再次处理，其他台词按原规则叠加。

继续使用已有 ComfyUI LoadAudio、D、混音节点，不新增外部本地音视频工具。新的音频依赖必须纳入任务指纹：上游主视频内容与候选变化使对应效果音及台词主视频过期；仅更改效果音后处理时重做预混主视频，不重生独立效果音。保留原方式任务身份与恢复能力。支持中断、指定段落、候选、重新生成与明确的依赖失败说明。

## 验证边界

验证应包含新旧模式、实际导出、原音及留白、同候选依赖、条件生成、先混音再参考、无重复叠音、恢复及失效、独立起镜、真实 DP 接续表演。真实 H3 音画同步与最终听感仍需要在生成机试跑；代码、离线图和 DP 文字通过不等于听感通过。
