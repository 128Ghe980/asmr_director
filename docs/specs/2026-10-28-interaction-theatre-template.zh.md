# 近距离互动小剧场模板

日期：2026-10-28。属于 Audio Quality V1；承接既有参考模板与逐镜 ASMR 链路，不新增路线阶段。

## 目标

用户给出「爱哥」目录的两个本地视频，希望新主题也能生成相似的镜头关系和表演感。模板提炼角色与听者的互动方式，不保留两片的具体剧情、角色身份、造型或对白。来源观察和时间锚点见[开发记录](../records/2026-10-28-aige-performance-template.md)。

## 可迁移约束

- 模板 ID `intimate-interaction-theatre`，名称「近距离互动小剧场」，固定 `listener_pov`。相机是接受互动的听者视点；听者安静坐着时镜头保持稳定，亲近感主要由角色俯身、歪头、探身与手部进入近前景产生。不能把第一人称等同于每镜走动、抖动或环绕角色。
- 开始先建立双方距离、眼高、角色正在做的事和操作区。角色的目光在听者与当前任务之间有原因地切换。转场或视点高度变化必须由剧情动作支持，不能凭空瞬移或插入旁观反打。
- 角色有当下意图和小反应：发现细节、短暂判断、提问、观察听者、认真操作、轻微打趣、恢复照料。按情境选用这些节拍，不把整套循环强塞给每句台词，不全程固定微笑或持续催眠口号。
- 听者不配音。提问后用目光、短暂等待及后续反应表达交流，不凭空添加听者的台词、正脸、决定或已经完成的交接。
- 一个短镜头只承担一个主要动作或反应。动作写清起始状态、接近/接触、停留和结束状态；双手职责、道具位置与上下镜连续。说话和动作用同一意图连接。
- 台词可自然、亲近并有小幅情绪变化；具体耳语强度、声音质感与表演者声线不作为来源已验证事实或克隆目标。
- 独立 ASMR 来自当前任务材料及接触方式，声位相对听者确定；安静观察可保持轻微环境/衣料声音，不为每个点头制造敲击或环绕。声音字段继续使用现有 `asmrSound` 与后处理配置，有声及无对白镜头同样适用。

## 实现边界

沿用 `CreativeTemplate` 的创作 prompt、场景、分镜规则与节拍，经过创意生成、采用、保存、分镜及校对进入已有链路。无需新增并行风格存储或第二套声音数据。

新模板拥有独立默认主题、角色和原创示例《雨停前的地图修补桌》。旧「禁令下的秘密交易」保留原示例和专属交易要求；商品展示、报价、A/B/C 不再无条件约束所有模板。未知模板 ID 的示例回退应保持中性，不返回旧交易剧情。

模板快照随工程保存；新增模板不自动改写旧工程或其已保存模板。模板详情继续折叠，界面显示可用创作内容，不显示内部分析过程和验证提醒。选模板只影响下一次创作设定；应用到已生成工程仍按现有采用流程。

## 验证

验证两个模板的默认设定和示例隔离、新模板锁定 POV、用户新主题不被固定场景覆盖、规则进入策划/分镜/声音规划、旧模板兼容、构建与实际界面。用不同主题的真实文案请求检查迁移能力；这些检查不等于最终 H3 画面、手部稳定性和声音质量验收。最终范围及回执见开发记录。
