# 逐段分镜参考模式

日期：2026-10-02。范围：现有 Audio Quality V1 工程编辑流程。

原连续参考复选框改为两个互斥的下一次生成选项：

- **连续镜头**（`continuous`）：延续相邻上一段可用分镜的场景、光线、构图与动作，使用当前段台词和已采用音频。
- **新镜头**（`new`）：优先依据工程剧情背景与当前台词设计新画面或相关位置。相邻上一段的可用分镜仅作次要画面参考；没有可用上一镜时可仅按背景生成。

第一条人声固定为新镜头。连续镜头要求相邻上一段分镜有效且完整，不跨过缺失、过期或未补全的上一段。浏览器及服务端均检查此条件。

每段「视频分镜」入口右侧新增紧凑图标切换按钮，链条图标表示连续镜头、取景框图标表示新镜头，配紫色及青色轻量底色、键盘焦点及包含当前状态/切换动作的可访问标签。点击只修改该段模式，不切换选段或打开面板。分镜面板用同一组单选选项，生成中两处均锁定。

偏好保存到可选 `videoPlan.referenceModes[clipId]`，已生成分镜用可选 `shot.referenceMode` 记录生成时模式。读取顺序为首段强制新镜头、显式偏好、已存生成模式、旧分镜是否有关联上一镜。兼容旧工程及原来源指纹；单独切换偏好不会改写或作废已有提示词。

手动及串行批量生成发送当前模式，并在保存前复核模式、来源、已采用音频和前镜关联。批量逐段保存成功后才开始下一段，因此参考刚生成的前镜。显式新模式只给文字模型上一镜标题、画面、动作、机位，不重复上一段台词、声音规则或完整 H3 prompt；最终音轨始终来自当前段。

未传 `referenceMode` 的旧 API 请求沿用原 `includePrevious` 行为。本次不接视频生成 API、不改变音频采用。验证见 [开发记录](../../records/2026-10-02-audio-quality-v1-storyboard-reference-modes.md)。
