## 范围

用户要求在第一步生成的位置加入分镜生成，目前 prompt 保持简单，后续再接入或补充官方 skill。本轮是可编辑的文字分镜：画面说明、角色动作及镜头说明，并关联当前文案；本轮不生成分镜图片。

文案继续作为音频生成来源。分镜属于策划元数据，不混入朗读文字，不修改音频片段或触发音频生成。已经认可的原 D 后处理及已采用音频批量下载保持现有行为。

## 界面

Planner 现有右栏增加紧凑的「文案 / 分镜」标签。两视图共用受限高度的内容区域及内部滚动，保留一屏工作台和现有台词选区编辑；左侧创作设定继续沿用桌面和小屏行为。

尚无分镜时显示简洁空状态，有有效文案后可点击「根据文案生成分镜」。已有分镜用编号卡片展示对应台词，以及可编辑的标题、画面、动作和镜头字段。紧凑的可选要求可引导重新生成；保存状态、撤回、下载、生成进度、取消和可重试错误沿用 Planner 约定。小屏单栏，操作与长文字不得造成横向溢出。

分镜按场景、动作与情节节奏组织。普通文案通常生成约 6–12 镜，硬上限为 24 镜，短文案可更少；一镜可以覆盖多条相邻语义短句。不能因为音频编辑器拆为 200 条短单元，就生成 200 个分镜。

## API 与校验

`POST /api/storyboard` 接收 `{ provider, draft, instruction? }`，复用 Planner 已配置的本地或外部文字模型。发送前校验文案。首版分镜 prompt 独立且简单，便于后续加入 skill 指导，而不必重做界面或存储格式。

响应包含 `storyboard`：

```ts
{
  version: 1,
  title: string,
  sourceFingerprint: string,
  shots: Array<{
    id: string,
    title: string,
    sourceSectionIds: string[],
    visual: string,
    action: string,
    camera: string,
  }>,
}
```

服务器按已经校验的输入附加指纹，不信任模型自己填写的来源。指纹包含文案标题、场景、角色以及按顺序排列的台词 ID 和文字。分镜 ID 唯一；台词引用必须存在于提交文案中，以有序相邻组覆盖全文，不能重复或漏掉台词。模型输出无效时显示可读生成错误，保留工作分镜；不能把本地模板冒充为模型生成结果。

生成复用 Planner 的取消与请求身份保护。生成中编辑内容、载入来源或撤回会停止请求；迟到结果不能覆盖新修改。失败或取消保留原有文案与分镜。外部模型继续沿用现有按用量计费行为。

## 编辑与来源

分镜与工作文案一起保存，进入同一撤回快照。本地编辑允许文字字段暂时为空，并限制字段长度与镜数；模型输入与采用仍在相应边界校验完整内容。

修改来源文案时保留可编辑分镜，通过指纹标记过期。界面说明「文案已更新」并提供重新生成；撤回文案修改后，指纹重新匹配即可恢复关联状态。拆分、合并、新增、删除或调整语义单元顺序都会影响有序 ID / 文字，因而改变来源。仅修改下次主题表单，不冒称现有文案已经重新生成。

切换标签需保留文案及既有选区编辑行为。新文案生成后不能把旧分镜静默当作匹配的新分镜。重新生成只在返回有效结果后替换，并保存先前状态供撤回。

## 持久化与工程来源

V1 本地 Planner 工作态增加可选分镜数据，对旧记录迁移或补默认值；没有分镜的旧草稿继续可读。保存沿用现有草稿边界，不含凭据。分镜元数据损坏时，在可安全恢复的边界独立丢弃分镜，保留有效文案与创作要求，不应连带丢弃整个工作态或工程来源。

`PlannerSource` 增加可选分镜元数据，采用文案时随来源保留。项目库自动保存、复制、安全版本、版本恢复及音频候选撤回，通过现有来源边界保留分镜。分镜不进入音频 Project JSON。

载入当前项目原稿时明确载入其分镜；若来源没有分镜，则清空当前工作分镜，不能保留其他项目分镜。来源载入可以撤回。切换项目继续尊重独立工作草稿，不能仅因来源 prop 改变就覆盖尚未保存的策划内容。
