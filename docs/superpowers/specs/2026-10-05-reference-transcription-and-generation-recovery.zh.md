# 参考音频原话识别与生成故障说明

日期：2026-10-05。既有人声导演与真实ASMR音效质量V1，父阶段仍进行中。

用户要求澄清“留空时使用仅参考音频”，添加选择语言后识别所选片段原话、供人工
校对修改的流程，并检查新正太音参考的VoxCPM2生成失败。本次不恢复SFX模型测试。

## 用户流程

2026-10-06布局追加：参考选择框144×32px、已保存参考播放器240×32px与添加/刷新
共用一条工具栏。面板宽度小于560px时，选择与管理同排，试听换到下一排。时长在
播放器、悬浮说明与可访问文本中保留；添加表单在栏下展开。其他录音试听尺寸和
所有识别/生成语义保持。

添加参考音频时保留MP3/WAV上传、选段与试听，新文件默认8秒；增加中文/英语/日语/韩语选择和
“识别所选片段文字”。默认中文，只识别当前1–30秒选段，结果显示在可编辑原话
框。识别结果可能有误，用户试听、校对或重写后自行保存；识别本身不添加参考、不
改profile、不生成候选。“仅参考音频”是参考使用模式：空原话只使用录音，有校对
原话时可同时使用录音和文字；与“当前范围/长文连续生成”生成方式分别说明。

上传失败、识别失败/取消不清除人工原话；新文件、语言、片段或人工原话改变后，
旧识别回复不能覆盖当前编辑。切片后保留可校对的文字并提示检查原话归属。新文件
沿用既有清空行为。识别期间阻止保存/生成等冲突操作，可取消等待；输入变更取消
旧识别。取消和卸载释放界面忙状态，服务端仍需等原生进程确认退出。

## 本地识别边界

`POST /api/voice-references/transcribe` 接收multipart文件、startSeconds、
durationSeconds、language，返回transcript/language/实际选段信息。沿用32MiB与
1–30秒验证、固定协议FFmpeg、16kmonoPCM16及完整片段校验，临时工作在仓库外。
使用本机已有faster-whisper-large-v3 CPU/int8及显式语言，禁止隐式下载模型。
运行采用现有VoxCPM2原生锁，跨tab/API与声音生成串行；180秒包含转换和识别，
取消/超时停止自身子进程并最多5秒确认退出。未确认退出保留工作目录/原生锁，
不能释放后再次并行加载模型。识别失败不写参考profile或工程资产，错误不泄露
内部路径、原生日志或密钥。

## 生成故障

22:20失败日志显示正太音15秒WAV正常读取后，低显存参考编码创建cuBLAS失败，
`CUBLAS_STATUS_NOT_INITIALIZED`，原生进程退出。不能据此判定缺原话，也不能仅
凭日志断言显存不足。UI应提示GPU初始化失败及可操作的检查方向。CLI的
`--n-gpu-layers0`仅控制BaseLM，不代表全部CPU；`--cpu`会切全部自定义组件，
不得在低内存设备上无提示自动重试或静默裁短已保存参考。

最多一次独立短参考/短句的有硬时限诊断，原15秒参考/profile/工程保持。独立8秒
参考已在13.922秒内成功生成1.44秒短句，原15秒恢复仍未验证。实际
结果、可用建议和剩余限制写入开发记录；声音识别与TTS验证串行，避免同时加载。
