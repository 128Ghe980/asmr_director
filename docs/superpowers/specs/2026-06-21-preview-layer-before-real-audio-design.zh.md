# 真实音频前的预览层设计

日期：2026-06-21

## 背景

当前应用已经完成 C+ 项目工作区：

- 左侧项目栏。
- 顶部工作区状态和操作栏。
- 中间编辑区，包括分镜、时间线、情绪曲线、校验和检查器。
- 右侧项目详情栏。
- 左右侧栏可独立折叠，并有 `专注编辑` 模式。

右侧详情栏已经给“预览层”留了位置，但目前只是中性占位。路线图下一步是 **真实音频前的预览层**：先让产品在界面和状态上像一个音频预览工作流，但不假装已经有真实音频，也不接真实生成服务。

## 已确认方向

采用 **C：混合轻量版预览层**，并加入一个硬约束：

> 左侧项目栏和右侧项目详情栏必须继续可折叠。预览 UI 不能长期挤压中间 Timeline。

留档 mock：

- `docs/mockups/2026-06-17-preview-layer-options-vertical.html`
- `docs/mockups/2026-06-21-preview-layer-c-collapsible.html`

其中 2026-06-21 的 C 折叠版 mock 是实现参考。

## 目标

- 把右侧预览层从单个中性占位升级成可理解的项目预览表面。
- 加入占位播放状态，但不做真实播放。
- 加入假波形 / 状态表面，并明确表达“尚未生成真实音频”。
- 加入轻量生成槽，覆盖项目、轨道和当前选中片段。
- 保持 Timeline 可用，继续支持左右栏独立折叠和专注编辑。
- 保持本地优先，并继续由同一个 `AsmrProject` 状态驱动。

## 非目标

- 不做真实 TTS。
- 不做真实 SFX 或环境声生成。
- 不做真实音频播放。
- 不从音频文件渲染真实 waveform。
- 不做后端任务或队列。
- 不做云端持久化、登录、计费、协作或发布。
- 不做破坏性 schema 重设计。
- 不做完整 DAW 时间线编辑。

## 用户体验

### 展开工作区

当左右两侧都展开时：

- 右侧项目详情栏展示：
  - 项目预览块。
  - 禁用或占位的播放控件。
  - 假波形 / 状态表面。
  - 可预览片段数、待生成片段数、队列中片段数、真实音频数量等摘要。
  - 项目混音、人声轨、呼吸轨、音效轨、环境轨的轻量生成槽。
- Timeline 和 Storyboard 显示 clip 的轻量生成状态。
- Inspector 显示当前选中 clip 的生成状态和资产槽。

这个状态用于理解项目预览准备度和素材覆盖情况。

### 专注编辑状态

当用户需要时间线空间时：

- 左侧项目栏可以折叠成窄 rail。
- 右侧项目详情栏可以折叠成窄 rail。
- `专注编辑` 可以一次性折叠两侧。
- 中间编辑区，尤其是 Timeline，必须明显变宽。
- 即使右侧完整预览层被折叠，Timeline 里仍保留轻量 clip 状态颜色。

这个状态用于调整时间和 clip 结构，而不是查看预览详情。

### 移动端行为

- 布局应该堆叠，不产生文档级横向溢出。
- 预览和生成槽信息保持可读。
- 折叠控制仍可触达，但移动端不需要完全模拟桌面 rail 宽度。

## 预览表面

右侧预览块应包含：

- 简洁标题，例如 `项目预览`。
- 占位状态，例如 `未生成` 或 `等待素材槽完成`。
- 禁用播放按钮或非功能性播放占位控件。
- 假波形 / 状态条。
- 明确显示 `真实音频` 数量为 `0`。

假波形必须是中性视觉。它代表预览准备度，不代表真实音频已经存在。

## 生成槽

生成槽应该轻量、仅本地展示。它可以从现有 `clip.generation.status`、轨道归属和项目时长中派生。

推荐槽位层级：

- 项目混音预览。
- 人声轨。
- 呼吸轨。
- 音效轨。
- 环境轨。
- Inspector 里的当前选中 clip 资产槽。

每个槽位可以显示：

- 名称。
- clip 数量或当前 clip 时间范围。
- 状态标签，例如 `待生成`、`可预览`、`队列中`、`失败`。

如果当前 schema 没有 `队列中` 这类状态，实现时可以为了 demo 从现有数据派生本地展示状态。但除非后续 schema spec 明确批准，否则不能修改导出的 JSON。

## 组件设计

建议组件边界：

- `PreviewLayerPanel`
  - 放在 `ProjectDetailsDock` 内。
  - 展示项目预览状态、假波形和项目级预览摘要。

- `GenerationSlotList`
  - 展示项目 / 轨道生成槽。
  - 接收派生后的展示数据。

- `PreviewWaveformPlaceholder`
  - 纯视觉占位组件。
  - 不读取音频资产。

- `generation-summary.ts`
  - 纯 helper，从 `AsmrProject` 派生预览和生成槽展示数据。
  - 不修改项目数据。
  - 不依赖 React。

现有组件继续保持职责：

- `StudioApp` 拥有项目状态，并向下传递派生数据。
- `ProjectWorkspace` 拥有 shell 折叠状态。
- `TimelinePanel`、`StoryboardPanel`、`ClipInspector` 可以显示轻量生成状态，但不拥有项目级预览逻辑。

## 交互规则

- 预览播放按钮是禁用或占位状态。
- 点击禁用预览控件不能暗示真实音频播放。
- 折叠和专注编辑只改变布局，不改变项目数据、选中 clip、校验、自动保存、导入、导出或重置行为。
- 现有导入、导出、重置行为保持不变。
- 本步骤的生成槽是信息展示。如果出现 `标记为排队` 这类按钮，除非实现计划明确纳入本地状态变化，否则应只是展示占位。

## 错误处理

- 现有校验问题继续显示在 Validation Panel 和字段级提示里。
- 音频未生成本身不是错误，预览准备度不能显示成错误态。
- 如果 clip 有 schema 校验问题，生成槽可以显示警示摘要，但详细错误仍由 Validation Panel 承担。
- 无效 JSON 导入行为保持不变。

## 测试

单元测试：

- 为预览 / 生成摘要 helper 增加测试。
- 覆盖项目级预览待生成状态。
- 覆盖轨道级槽位数量。
- 覆盖选中 clip 状态派生。
- 确认占位模式下真实音频数量仍为 0。

浏览器验证：

- 桌面展开态显示右侧预览层和生成槽。
- 专注编辑态或折叠侧栏后，Timeline 明显变宽。
- 左右侧栏仍可独立折叠。
- `专注编辑` 仍可折叠两侧并恢复两侧。
- 移动端没有文档级横向溢出。
- 加入预览 UI 后，导入、导出、重置仍可用。

## 实现约束

- 保持当前 ASMR Project schema 和导出 JSON 格式不变。
- 保持 C+ 工作区 shell 和折叠行为。
- 使用简洁中文界面文案。
- 视觉方向延续当前 Studio Console：专业工具优先，克制 ASMR 氛围其次。
- 不加入真实播放、真实生成资产或后端状态。

## 验收标准

- 应用采用 C 混合轻量预览方向。
- 右侧详情栏包含可理解的项目预览表面、假波形 / 状态条和生成槽。
- Timeline、Storyboard、Inspector 展示轻量生成状态，但不干扰编辑。
- 左侧项目栏和右侧详情栏仍可独立折叠。
- `专注编辑` 仍能给中间 Timeline 释放明显宽度。
- UI 明确表达真实音频尚未生成。
- 现有编辑、校验、持久化、导入、导出、重置和项目 shell 行为仍可用。
- mock 和中英文 spec 已提交，方便未来 AI 接手和上下文压缩后恢复。
