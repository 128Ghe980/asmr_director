# 用户添加参考音频

日期：2026-10-05。现有路线：音质 V1，仍进行中。

后续修订：新文件默认8秒，增加语言选择、本地选段识别及手工校对，参考模式与
生成方式分别说明；原15秒正太音保持。见 [识别与生成诊断](2026-10-05-reference-transcription-and-generation-recovery.zh.md)。
以下初始15秒与无ASR描述为首次交付契约，由后续修订覆盖对应行为。

现有网页只能选择服务端配置的声音。新增 VoxCPM2 参考声音旁的导入入口，用户无需
手动编辑运行配置即可增加录音。GPT-SoVITS 沿用其现有单声音配置。

## 使用流程

点击 **添加参考音频**，选择 MP3/WAV，试听原录音，填写名称并选择起始秒数、片段
时长。初始选取前 15 秒，可修改；每条参考 1–30 秒，这是平台资源控制规则，不是
宣称模型有该硬性上限。准确参考文本可选；不填时只提供“仅参考音频”，不编造转录。
添加成功立即进入列表并选中，不自动生成或采用音频。

本轮用户授权的初始文件为 `H:/comfyui/output/sd2素材/正太音/正太音.mp3`，约 108 秒。
按前 15 秒准备 **正太音**，完整 MP3 保留。原两份参考与默认声音不变，工程文案、
编排、已采用音频和候选不会因导入/选声音而改写。

## 接口与保留

`POST /api/voice-references` 接收 multipart：`file`、`name`、可选 `promptText`、
`startSeconds`、`durationSeconds`。源文件上限 32 MiB；起始位置为非负有限数字，
时长为 1–30 秒。服务端分配安全 ID 和文件名；上传字节，不开放任意服务端路径读取。
原上传、转换录音和来源记录存放仓库外。FFmpeg 将所选片段转换为 16 kHz 单声道
PCM16，核对完整、有限、非静音 PCM 及选取时长；超出原录音的范围报错。

成功返回 `{ reference, catalog }`，只含安全 ID、名称、模式及试听 URL；工作台即时
更新目录并保存新选择。`GET /api/voice-references/[referenceId]/audio` 试听标准化
参考，不向浏览器返回本机路径。既有生成来源指纹继续使用真实参考内容。

配置追加须跨上传串行、原子发布，保留旧字段、参考与默认项，保存写入前备份。坏文件、
超时、取消及发布前失败不改变配置；取消恰好发生在已完成发布之后时，通过刷新目录
恢复已添加项，不声称回滚成功。转换子进程隐藏窗口、有明确时限，参数数组、不调用 shell。

导入忙碌状态阻止冲突的逐段/批量生成与声音切换，不伪装成“正在生成”。失败可重试，
取消/离开后的旧响应不能更改新选择。添加参考无需模型推理、ASR、付费服务或安装依赖。

## 验证

后端/接口覆盖正确转换、坏文件/容量、时间范围、取消、写入失败、并发追加及安全试听。
前端覆盖成功后即时选择、保存/刷新、模式、重试、忙碌、迟到响应及手机布局。实际导入
用户 MP3，核对标准 WAV 并试听；这只确认参考准备，不能代替生成声音的听感验收。
核对原参考、用户 MP3、工程素材以及另项空间工作台源文件保持。真实结果记入开发记录。
