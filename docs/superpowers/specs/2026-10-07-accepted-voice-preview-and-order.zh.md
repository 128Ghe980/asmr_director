# 已采用语音整体预览与台词排序

路线：既有 **人声导演与真实 ASMR 音效质量 V1**，继续以 [ROADMAP](../../ROADMAP.md) 为唯一来源。[English contract](2026-10-07-accepted-voice-preview-and-order.md)。

原“生成整段”要求全部轨道素材齐备。本功能用于工程尚未完成时，合并已采用语音试听，并下载同一份 WAV。

## 整体预览

- 文案批量操作下增加紧凑预览栏，显示已采用/全部台词数量。点击后合并，提供原生播放器及 WAV 下载。
- 仅收取当前 `voice`、`asset_generated`、`asset://clip/<asset_id>` 精确一致的素材，按 start 稳定排序。候选、历史、未采用/mock 素材及其他轨不进入。
- 按真实 WAV 完整时长连接，旧占位比录音短也不裁音。优先保留本段 `pause_after`，否则只推导到原紧邻下一段的等待；跳过未采用台词，不把其语音时长补成静音。最后采用段不追加尾部等待。
- 统一 PCM16、48 kHz、双声道；单声道复制双耳，立体声保留分离，PCM16/24 输入按需重采样。输出为原声，不叠加空间、淡入淡出或响度归一，不调用生成/识别模型，原文件与采用记录保持。
- `POST /api/assets/voice-preview` 输入 `{project}`，返回 `{audioUrl,filename,clipCount,skippedCount,duration,size,expiresAt}`。原生 `GET`/`HEAD` 可重复读取、支持 Range；`download=1` 下载，`DELETE` 释放。
- 切换项目、采用/文本/顺序/等待变化时清空预览、取消请求，迟到结果忽略并释放。支持取消、卸载及 `pagehide` 清理，StrictMode 重接媒体节点后仍有有效 src。
- 串行整理，分块写出自有临时目录：最多 2,000 段，单源 128 MiB/10 分钟，整体 20 分钟，整理上限 120 秒；最多三份预览，30 分钟过期。释放后不接受新读取，活动流关闭后再删除目录。`ASMR_VOICE_PREVIEW_TEMP_ROOT` 可指定临时根目录。

## 台词排序

每条人声右侧显示紧凑上/下移按钮；首末及生成、参考导入、分镜等忙碌时禁用不可执行操作。交换相邻完整台词，保留 ID、原文、采用素材、生成数据及分镜关联。等待随台词移动，按完整已采用时长重排受影响的人声后缀；非人声轨与情绪数据保持，必要时只扩展工程边界。保持当前选中段，沿用编辑历史、取消/版本与持久化流程，可准确撤回；不删除或重新生成原音/候选。

## 验收

验证真实 PCM 尾部/重采样、路径、Range/会话、取消、迟到、StrictMode、移动保留采用与撤回回归；完整 TypeScript、相关 lint 和正式构建。在原 3001 origin 验证用户部分完成的工程、原生播放/下载、移动后撤回与刷新、桌面/窄屏紧凑布局，以及参考/原音/候选/其他会话文件保持。不需要模型任务。
