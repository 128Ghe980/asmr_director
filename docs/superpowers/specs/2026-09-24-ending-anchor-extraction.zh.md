## 用户请求与实例诊断

用户询问用于调整语气的不常见标点是否导致不匹配，提出用末尾词或字定位截取结束，并希望 API 判断作为最后兜底。内容核对与声音切点安全继续分开；完整原音始终保留，候选不自动采用。

已有归一规则会移除标点及其他非字母、非数字符号，包括 `~`、`～`、省略号、破折号和括号。`[轻声]` 一类标注中的汉字仍作为正文保留。本次不删除标注词，不修改实际合成文字、语速、省略号策略、参考音或模型参数。

本次失败目标为“来~~，面来啦！慢点儿吃，小心烫。汤也喝一点，暖胃。”，归一后 18 字。识别目标部分“来,面来了,慢点吃,小心烫,汤也喝一点,暖胃”归一后 17 字：一处“啦 → 了”、一处少“儿”。9 月 23 日规则在等长检查时直接拒绝，还没有进入安全切点验证。即便采用普通编辑相似度，`1 - 2/18 = 88.8889%` 也低于旧的 90% 替字阈值，因此不能把问题归因于标点。

## 已实施的有界回退契约

原有完全一致／90% 等长替字路径保留比较格式和行为。单独的 `bounded_edits` 核对只在以下限制全部满足时允许增字、漏字和替字：

- 归一目标至少 10 字。
- Levenshtein 编辑总数不超过两次。
- 相似度为 `1 - 编辑数 / max(目标字数, 识别字数)`，至少 85%。
- 拒绝调序／相邻交换及新增重复短语。
- 候选目标前缀的前两个归一字必须完全一致，末尾落在完整 ASR 词结束位置。

85% 是末尾辅助回退的独立门槛，不暗改原有阈值、不全局删除“儿”、不把同音字判为完全一致。结果记录模式、阈值、增／删／替字数量、编辑总数以及归一后的源文／识别文本。旧规则已接受的结果继续保持旧格式，兼容历史候选。

本地末尾锚使用至少两个、最多六个归一字的精确共同后缀，优先较长的可用后缀。完整前缀的有界核对与紧邻后文必须共同选出合理开头搜索范围内唯一的候选结束位置。有效前缀较早处有同词不单独阻止截取，但不能跳过目标结束与后文之间额外重复的尾词。只出现相同末尾词不能让无关或残缺正文通过，也不能跳到完整录音很远处的同词。

## 声音验证与内部边界

### 10月7日：后文语气词衔接修复

上述目标内容阈值保持。真实目标“今天是不是又加班了？眼睛都红红的。”在去标点后完全一致，但后文识别是“嗯面快好了”，而定位期望是“面快好了”。后文前缀的严格规则在裁剪检查前拒绝了这条录音，生成提示又误写为目标台词有差异。

只允许目标前缀**完全一致**后紧接一个独立带时间戳的原音ASR词“嗯”作为后文桥接。其他额外词、重复语气词、“嗯面”合词、后文缺首字/错字或目标存在近似差异均不能借此跳过。独立识别完整剩余右侧，仍受既有120秒源音上限及worker期限限制；只保留短后文窗口会导致锚点误识。右侧segment文字及整词前缀必须从开头精确包含完整给定后文，允许前面有一个独立“嗯”；只有原音独立“嗯”时间及静音保护证据齐全时，才允许右侧识别器省略这一语气词。禁止向后扫描碰巧匹配的锚点。左侧及最终目标核对仍要求完全一致。候选仅搜索目标末词结束加80ms至原音“嗯”开始减80ms之间，真实静音至少160ms；禁止按字数拆时间戳。失败仍保留完整原音。

仅最终检查完成且目标完全一致的结果可保存有界 `continuationBridge` 证据，包括原音字词索引/时间及右侧真实独立识别文本；服务端另要求裁剪静音证明在“嗯”之前。界面区分完整录音、定位用后文及未采用的试裁结果。旧候选的误导性衔接提示仅在显示时修正，不改工程存储和音频，不改变合成参数，也不自动重生或采用录音。

每个末尾辅助截取都必须搜索附近真实静音，并对切点左右分别独立识别。实测静音需保护切点两侧，不能只依赖 ASR 词时间戳。目标侧使用完整目标的有界编辑核对，后文侧仍严格检查开头。最终裁片的整段转录与拼接词转录归一后必须一致。声音边界不安全或无法验证时，继续返回完整原音并标记需确认。

内部子句边界改用已通过的编辑对齐映射，不能继续沿用未扣除漏字的累计字数。只接受唯一明确且落在完整 ASR 词结束处的映射。子句末字被删、重复文本附近映射不唯一、或边界位于一个 ASR 词内部时，不能猜测时间。内部停顿继续取相邻词真实时间戳差，不按平均语速或字数比例推算。

## API 兜底范围

已实现的 API 兜底只能从本地计算出的有界候选结束位置中选择，响应只含已有词索引或 `null`；应用从原本地候选中取回对应识别前缀。API 不能编造文字、时间或候选索引，不能越过内容门槛，也不能绕过本地声音验证直接批准截取。本地确定性流程成功时不需调用 API。

兜底复用已配置的外部 Planner 提供方，只发送有界的目标／识别文字及邻近词索引，不发送 WAV 音频、时间戳、本地路径或无关的远处后文。仅在本地源定位失败或存在歧义、且有合格候选端点时调用一次，默认超时 15 秒。选出的端点必须再通过一轮完整本地验证；没有 API 重试、递归兜底或原生合成重试。未配置、返回空、响应不合法或请求失败时，保留完整原音交付与本地识别证据；两轮之间仍响应取消。识别记录分别展示 API 已选择／未确认／不可用状态、末尾锚或 API 的定位来源，以及实际切点验证。
