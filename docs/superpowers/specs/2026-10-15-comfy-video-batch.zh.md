# 视频项目包与 ComfyUI 批跑器

日期：2026-10-15。状态：用户已确认设计，初版本地实现与验证完成；真实生成主机及浏览器视觉验收待完成。属于现有 Audio Quality V1 的音频／分镜交付扩展，不新增顶层路线。验证见[开发记录](../../records/2026-10-15-audio-quality-v1-comfy-video-batch.md)。

## 已确认的产品约定

- 导演项目导出一个可搬到另一台生成主机的 ZIP，内含项目清单、逐镜素材、工作流和独立运行程序。生成主机运行已有 ComfyUI；第一版程序使用 Python 标准库和 FFmpeg，不打包模型或依赖当前导演网页常开。
- 当前活动的短句／整段页各自导出；保持当前镜头显示顺序，每条有对白／无对白条目是一镜。时间线仅可用于恢复现有显示顺序，不导出或执行 start、pause_after、工程总时长、混音时间表；不插等待、定格或自动过场。
- 每个有对白镜头仅带一份实际已采用 WAV。没有原声／后处理双份，没有全局音色限制、角色映射或在生成端再次选声音。音频被当作文件处理：测量实际长度，同一文件供 H3 参考及最终视频封装，不重新合成人声、不变速或裁掉对白以迁就视频。
- 角色参考图是本批可替换输入：导出时可携带，也可在生成端指定／替换。`I:/temp/爱哥.JPG` 只用于这次测试，不写死、不开新角色库、不把私人图片提交到仓库。
- 无对白镜头保留在指定位置，时长大于 0 且成片不超过 5 秒。DeepSeek 根据本镜描述、场景及前后镜头文字生成简单画面和自然环境底噪描述（如雨声、风声、房间底噪），无对白、配音或音乐。无需输入 WAV；保留 H3 生成的环境音。
- 连续镜头只做顺序执行中的尾帧参考：取本次上一镜实际输出尾帧作为 Picture 2，同时保留人物 Picture 1。上一镜没有成功结果则退回人物参考继续；不借更早镜尾帧，不逐镜审核、不建质量依赖链、不自动作废或重做后镜。首镜从新镜头开始。
- 整批自动尝试全部镜头；有限技术重试后记录错误并继续。中断恢复必须保存并核对已有 ComfyUI prompt_id，不能因连接中断盲目重复提交。生成效果由用户在完成后判断，支持选择某镜重做。
- 可选在全部镜头成功且输入／输出校验有效后，按顺序生成预览片；不缺镜合片、不采用工程等待、不重新调用模型。预览可以统一编码，已有单镜文件保持不变。
- DeepSeek 复用导演端已有外部 API 配置，生成程序只执行已准备好的提示词。密钥不进入项目包。

## 工作流基线

用户提供的实际文件为 `I:/temp/asmr04.json`（输入消息中的 amsr 为拼写差异）。对比 03，唯一执行变化是 `LoadAudio #24 → CreateVideo #11.audio` 替代 `VAEDecodeAudio #4 → #11.audio`；同一 #24 仍连接 H3 的参考音频。

独立 API 模板保留模型、20 步、采样器和加速参数；将提示词、长度和输出路径直接注入，移除与批处理无关的文本拼接及 CLF 取帧插件依赖。尾帧用 FFmpeg 提取并上传。默认沿用原 ResolutionSelector 的 0.8MP 横屏（1216×672）、24fps，可在运行端配置。

有对白使用 04 的原音频封装；无对白断开输入音频参考并恢复生成音频封装。两种模式与 new／continuous 组合。现有第二张参考图仅提供模型参考和文字引导，不宣称硬首帧逐像素一致。

长度按真实素材计算，生成足够的 `17k+5` 帧后修整输出：5 秒直接代入旧公式得到 124 帧／5.1667 秒，必须同步修整环境音和画面，使无对白结果不超过 5 秒。按音频长度生成足够画面并保留完整对白；不用工程等待。

## 项目包契约

包根包含 `project.json`、`workflow_api.json`、`runner.py`、`run.bat`、`README.zh.md`，可选 `references/character.jpg|png|webp`，以及每镜目录 `shots/001/`。有对白目录只有一份 `audio.wav`，可附便于查看的 `prompt.txt`。

`project.json` 使用 `format: "asmr-video-package"`、`version: 1`，包含 `projectId`、`title`、可选 `characterReference`、`workflow` 和按顺序排列的 `shots`。每镜包含 `id`、`order`、`kind: "speech" | "ambient"`、`referenceMode: "new" | "continuous"`、`prompt`、`durationSeconds`，有对白另含相对 `audio` 路径。允许添加来源信息；不得保存密钥、浏览器 URL、机器绝对素材路径或运行中进度。

先检查全包素材：缺已采用音频、当前分镜字段或环境底噪描述时明确报段号，不静默漏镜。旧无对白数据保持可加载，但需要补环境声分镜；旧超过 5 秒的条目提示用户调整，不偷偷迁移。仅检查本镜来源，不因前镜指纹变化级联禁止导出。

## 验证要求

- 单元及组件：素材与镜头稳定配对、一镜一音频、活动语音库隔离、无时间线等待、可替换参考图、环境声上下文、取消及迟到请求保护。
- ZIP／API：实际 WAV 字节、CRC、真实时长、上传大小及格式、路径边界、错误清理、下载令牌流式传输。
- 批跑器：干跑与模拟 ComfyUI 提交／轮询／下载、正确音频连接、尾帧回填及失败降级、断点恢复、不重复未知任务、输入变化只重跑本镜、无对白 5 秒限制。
- 本机使用真实参考图及合成测试 WAV 做包→干跑和 FFmpeg 媒体验证，不调用 TTS／ASR／付费 DeepSeek，不伪称远端 H3 实测。生成主机上的真实画面／口型／环境音及节点兼容性另行验收。

## 每镜多候选与等待交互

运行器每镜可生成 N 个候选，N 为正整数、默认 1。候选号和 seed 在重试／恢复后保持稳定；增加 N 只补缺少候选，减少 N 保留已有文件。旧 version 1 单结果状态自动接入候选 1，不为迁移重新提交模型任务。每个镜头／候选分别保存提交身份、状态、来源和输出，项目包仍保持每个有对白镜头一份 WAV。

连续镜头的候选 k 只取相邻上一镜候选 k 的尾帧；前镜缺少该候选或失败就退回角色图，不借更早镜头或其他候选号。不因更换／重做某结果而使后镜失效。支持选择镜头、重做某镜本次全部候选，或指定 `镜头:候选号` 重做；按最后一个冒号拆分，因此镜头 ID 本身可含冒号。

可选合片按候选号分别检查全部镜头。N=1 保持 `preview.mp4`，N>1 输出 `preview-c001.mp4`、`preview-c002.mp4` 等；某号缺镜只禁止该号预览，其他完整候选集合可以正常合片。已有逐镜文件保持。

等待分开处理单次 HTTP 请求（默认 30 秒）、持续断线（默认 300 秒）和可选任务总等待（默认 0，健康连接时不限）。排队／生成中不算模型失败，不能据此重发。默认每 15 秒发送状态心跳；未知提交必须先通过 queue／history 对账，明确重做也不绕过这一点。

GUI 后台线程执行任务，显示当前镜头、候选号、阶段、完成数和用时；单次 HTTP 阻塞时，窗口自身计时器仍刷新。事件队列、每次消息处理及约 2,000 行可见日志均有上限。候选数和最长等待是主要设置，选择镜头与重做放在可选高级区。停止只终止本地后续提交和等待、保留任务身份，不调用 ComfyUI 全局 interrupt；已提交任务继续在远端运行，下次先对账。CLI Ctrl+C 说明恢复方式并返回 130；HTTP 阻塞期间的停止请求在该请求结束或超时后生效。

使用纯函数／模拟测试验证参数默认值与校验、GUI 单位转换、有界事件、进度格式和中断，不实际打开 GUI 或调用模型。核心另测旧状态迁移、同号连续、N 增减、seed 稳定、逐候选恢复／合片、健康任务超过旧一小时时限，以及断线／停止边界；真实生成主机验收独立保留。

状态格式独立升级为 version 2；保留原输入指纹的 RUNNER_VERSION=1 语义，旧成功候选 1 不因程序升级失效。技术重试沿用 seed，明确质量重做换 seed 并保留回执历史。已有未确认任务在本次恢复成功时，抑制同输入的额外质量重做。已确认输出的完整原片通过 SHA 校验即可离线封装，跳过远端节点／history 查询；原片缺失时按已存输出位置恢复下载，不重复生成模型。

提示词、基础seed等输入改回旧值时，复用SHA验证完整且输入相符的历史成功结果，不再提交模型。基础seed与其他保留任务碰撞时使用稳定替代seed。明确重做的代数超过全部保留历史，恢复旧结果后也不重复旧代。已有成片被外部修改时，恢复封装或新结果另存路径，已有suffix的当前文件同样不覆盖。
