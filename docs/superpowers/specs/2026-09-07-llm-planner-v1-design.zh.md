## 产品行为

工作台增加“AI 创意策划 / 工程编辑”视图。主题必填；时长 1/3/5/10 分钟，角色、风格、补充要求可选。默认中文和本地 Ollama，也支持服务器配置的外部 API。

生成完整可朗读文案，包括标题、场景、角色与 2–12 个段落；每段独立保存台词、导演提示、音效建议、情绪/风格/语速、位置和段后留白。导演说明不能混入 TTS 台词，音效建议不能冒充已具备的真实素材。

支持直接编辑、指定一段 AI 改写、取消、下载文案，以及本次会话内最近 5 次 AI 更新/来源载入的撤回。请求期间锁定冲突编辑；失败和取消保留旧稿，晚到结果不提交。

独立本地草稿保留表单 brief 和生成时 draftBrief。修改主题不会偷偷替换原稿来源，界面说明需重新生成。自动保存失败明确提示；损坏存储在用户主动编辑前不覆盖。

采用前验证，创建新工程并给原工程留安全版本。项目库保存策划来源快照，可重新载入；后续工程台词编辑不会反向改写原始策划快照。重置/导入替换清除旧来源；版本保存、恢复同时处理来源。

## 数据与调用

`PlannerBrief/Section/Draft` 使用独立 Zod schema。确定性编译器创建五种固定轨道，只有人声轨包含台词；资产全部待生成。导演提示和音效建议保留在 `plannerSource`，不混入 Project JSON。

`ai-asmr-studio:v1:planner-draft` 保存工作草稿，不含 API 密钥。项目库 entry/revision 的可选 `plannerSource` 经校验后加载；坏元数据不会丢弃有效工程。

`GET /api/planner` 返回非敏感模型目录（configured 只表示配置齐全）。`POST` 区分 generate/rewrite，再次验证请求与结果；单段改写仅返回并替换目标段。

Ollama 使用 `/api/chat`、JSON schema、非流式、`think:false`；外部采用兼容 Chat Completions JSON mode。地址/密钥/模型来自服务器环境变量，外部发送与费用在界面说明。请求、响应、tokens、总时长均有限制；结构失败最多修复一次，错误不回显上游正文/密钥，没有伪模板降级。JSON Content-Type 与同源 Origin 检查防止简单跨站触发模型。

## 时长边界

目标时长只指导写作；编译器估计说话时长和段后留白，不裁文、加速或用空白强行凑时长。段后留白与音质 V1 的内部语义组停顿配方独立。

真实人声资产记录 PCM WAV 实际时长。带策划来源的工程自动延长过短片段、顺延后续时间和情绪曲线、延长跨边界循环环境声；较短音频保留计划留白。普通旧工程保留原行为。并发生成只忽略由时序调整产生的人声起点差异，文本/时长/参数变化仍使旧结果失效。
