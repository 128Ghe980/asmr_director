# Qwen 剧情配音台

日期：2026-10-06

用户要求独立网页：输入剧情文案，调用 API 生成指定人数的角色对话，给角色分配现有参考声音，再合成整段。首个交付样例为八句古风剧情《雨渡送药》，女角色用 `normal_zh`，少年用 **正太音2**，其稳定 ID 为 `user-dd2a4e32-e72d-4e80-bf7d-96611831b52b`。

## 运行与契约

- 新代码、缓存、临时文件及输出都位于 `I:/AI/qwen3-tts-dialogue`，网页7866只绑定127.0.0.1。
- 轻量后端只在服务端读取既有策划 API 的 URL/KEY/MODEL。密钥不进入浏览器、日志和输出。文字 API 只接收剧情要求与对白要求，不接收参考音频。
- 文案返回标题、1–8个唯一ID角色及2–24句有序台词。每句拥有唯一ID、有效角色外键、1–250字文本及有限的情绪/强度/语速枚举；API 无权选择文件或任意TTS参数。
- 用户可编辑对白、逐角色分配及试听参考、设随机种子与0–1500ms停顿，再提交固定快照合成。生成文案和生成音频是两次明确操作。
- 每句通过现有7864的Gradio `/run_one` 调用，graft模式、中文、正常发声、上限512token。新服务不加载第二份显卡模型，与原社区页共享现有队列。
- 同时只运行一个剧情配音任务。取消在句间生效，正在上游生成的一句可能完成；已生成片段保留。失败或取消均明确标记，并保留可用片段。
- 单独的继续操作仅在脚本、声音绑定和参数与未完成旧任务完全一致时创建新任务。校验连续已完成前缀的WAV/JSON哈希、参考哈希和真实参数后复制原字节，只生成缺失句；不修改源任务。内存失败停止并保留诊断，恢复不自动重启上游。
- 逐句原WAV/JSON保持字节复制到任务目录；检查24kHz单声道PCM16后按真实采样数与指定停顿拼接，不做响度归一化。提供整段WAV、UTF-8对白、带时间字幕SRT及来源清单下载。
- 浏览器localStorage保存可编辑草稿与作业ID，刷新可恢复最近结果。编辑使旧结果显示需要重新生成，但保留试听；不自动播放，同一时刻仅播放一个播放器。

## 固定指令与单句重生成扩展

用户随后反馈指令有效、声音一致性过低，要求逐角色固定指令与单句重生成。本次控制输入条件，不提前判定实际声音已更一致。

- `options.strong_consistency` 为严格布尔值，旧请求/manifest 缺省为 false。`options.character_instructions` 按当前角色 ID 存完整指令；启用时每个角色都须有有效 1–250 字的非空指令。首尾空白统一归一化一次，内部换行保留；该角色所有句子使用同一完整有效字符串，不追加逐句情绪/强度/速度。关闭时保留浏览器草稿，但有效选项比较忽略这些草稿，恢复逐句表达。
- 有效快照在强模式下忽略逐句 delivery，在普通模式下忽略未启用的指令草稿。没有新字段的历史任务和 localStorage 保持兼容；角色草稿按稳定 ID 保存、刷新保留，不涉及密钥。
- 单句请求同时提供 `reroll_job_id`、`reroll_turn_id`、`reroll_seed`，不能与继续任务并用。源任务必须完整完成，且有全部有序片段。仅目标句的文本和有效表达可改变；角色资料、声音绑定、目标 ID/说话人、其他有效台词、顺序/数量和有效全局选项都需匹配。全局变更要求整段重生成。
- 目标种子独立为 0–2147483647 的整数，不改全局种子或其他句实际种子。网页要求与该句上次实际种子不同，默认 `(old_seed + 1) % 2147483648`；直接 API 可同种子改文复现。`planned_turn_seeds` 保留各句混合实际种子及未完成目标意图，支持再次重生和恢复；公开结果逐句显示实际 seed。
- 复用前核验复制文件/原文件的 WAV、JSON、SHA、实际参数、当前参考 SHA 和帧数。工作进程按台词顺序推进，未变句原样复制、仅目标调用生成器；依据新采样数重新计算全部起止位置、静音间隔和字幕时间。另存新任务与来源记录，不覆盖旧任务。
- 整段、继续和单句使用同一任务门锁及原有上游队列。目标失败/取消仅保留已完成连续前缀，不将后续复制片段误当完成前缀；继续按保存的逐句种子计划补齐。不自动重启模型、不处理响度、不额外加载显卡模型。
