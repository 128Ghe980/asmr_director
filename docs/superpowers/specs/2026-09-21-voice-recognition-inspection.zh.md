# 语音识别对照与生成来源核查

日期：2026-09-21。记录既有语音生成修正与调查，不新增顶层路线，也不构成新的听感验收。[English version](2026-09-21-voice-recognition-inspection.md)。

## 目的与交付

用户需要看到 ASR 实际识别到什么，以及为什么所选短句没有被截取，同时仍能试听、下载每次完整原音。识别只是核对证据，不能扣留原音、触发重新生成，或悄悄放宽文字及安全裁剪规则。

候选和原音记录都提供默认折叠的“识别对照”。其中区分目标台词、完整生成窗口的识别、尝试裁剪后的识别。完整窗口可能包含后续短句和中性补句，不能当成只识别了目标短句。截取失败时明确说明保留完整原音；核对通过的截取显示保留时间范围。原音记录区域始终说明其试听／下载对应完整原音，即使另处已经成功提取了目标片段。

对照中展示检查阶段，以及可取得的定位期望文字和实际累计的识别前缀。历史记录缺少证据时显示“未保存识别文本”，不能用目标台词伪造识别结果，也不能据此宣称检查通过。文字区域在折叠面板内滚动，不持续撑高工作台。

## 识别契约与持久化

分析成功／失败、分组候选结果和原音记录元信息都可携带可选 `recognition`。旧记录无此字段时保持兼容。对外只含有界文字与时间戳，不含原生日志、本地路径或原始异常消息。

- 必填：`stage`、`sourceTranscript`（最多 8,000 个 UTF-16 单元）、`expectedText`（500）。
- 可选：`sourceWords`（最多 2,000 项；每项文字最多 200，起止为 0–120.1 秒有限数且结束不早于开始）、`targetTranscript`（8,000）、`followingText`（1,500）。
- 可选定位证据：归一后的 `expected`（1,500）、实际累计的 `recognizedPrefix`（2,000）及有界小写字母／下划线 `reason`。
- 阶段包括输入检查、完整原音识别、目标句定位、后文衔接定位、裁剪边界检查、裁剪后识别、裁剪后台词核对、检查完成、未取得结果。阶段说明识别／检查执行到了哪里；`complete` 本身不保证后续文件发布成功。

Python 在完成原音识别后立即原子写入 `analysis_incomplete` JSON 检查点，后续阶段或裁剪识别产生时继续更新。独立进程及复用 worker 在超时／中断时可保留最后一个有界检查点，避免已完成的 ASR 随临时目录清理而消失；最终成功／失败覆盖检查点。后端校验 schema 与目标／后文身份后，将证据关联到对应原音及候选，并随持久化保留到刷新后。某个候选切点失败的定位证据不得串到下一个候选切点的结果中。

通用异常使用安全诊断码。识别证据不能覆盖最终检查结果，也不能直接授权采用裁片。精确文字锚点、内容匹配、裁后独立识别、实测静音保护规则均保持不变，包括本次观察到的“啦／了”差异仍会失败。

## 真实调查

证据根：`I:/AI/asmr-director-recognition-inspection/2026-09-21`。本轮调查复用已有 WAV，运行离线 CPU／int8 faster-whisper large-v3，没有重新合成替代声音或采用诊断裁片。

当前原音为 `I:/AI/asmr-director-voice-work/long-text/57dfefdd-1e15-4f1f-b663-067919bb3a96/group-1-take-1-source.wav`，时长 23.36 秒。目标台词为“回来啦？外面是不是很冷？”，后文为“快进来，”。

- `real-integration.json` 记录 `source_alignment` 阶段的 `uncertain_word_alignment`。ASR 开头是“回来了”，目标是“回来啦”；精确开头锚点在查找静音边界之前就失败了。保留的识别前缀包含定位过程中实际继续尝试的后续文字。
- `boundary-acoustics.json` 记录 ASR 目标末词结束 2.30 秒、下词开始 2.40 秒，即时间戳间隔 100 ms；独立测量波形则发现 2.37–2.63 秒共 260 ms 静音，候选中点为 2.50 秒。ASR 时间戳间隔不等于物理静音长度，原始失败也不能证明没有静音边界。
- `boundary-probe.json` 对 0–2.50 秒左侧独立识别，仍得到“回来了外面是不是很冷”，严格目标核对失败；对 2.50–3.65 秒右侧识别得到“快进来”，严格通过。因此，即便跨过首次定位失败，该候选也没有满足未修改的裁后独立核对。没有采用探测裁片，也没有引入同音替换规则。
