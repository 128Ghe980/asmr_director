## 用户决定与路线范围

用户指出，现有自动分段替用户决定了修改、重生成的大小，整段音频又使句子之间的等待无法独立编排。用户要求由自己指定文本范围，生成途中也可以修改，并大改工程页：上方左右两块分别内部滚动，时间线移到下方，右侧常用声音操作优先。

本轮是用户批准的现有 Planner 与工程交互修正，不新增编号路线，不代表音质 V1 验收通过。已获认可的原 D 空间处理，以及每次完整原音必须可试听、下载的规则继续有效。

## 文本编辑约定

- 在一个段落内选中文字，即确定改写或独立生成的范围；光标也可以定义分段位置。范围使用 textarea 的 UTF-16 偏移，拒绝越界、倒置及拆断代理对的边界；纯空白选区不生成空台词片段。
- 策划和工程均支持手动修改、插入、删除、拆分和合并。策划允许本地保存临时空段，避免清空文字就丢失草稿；采用工程和请求模型时仍要求输入完整有效。
- AI 范围改写只返回所选文字的替换内容。应用保留原来的前缀、后缀和未涉及的段落元数据；提供上下文不等于授权模型改写上下文。工程复用 Planner 模型接口，在选定片段周围提供有界上下文。
- 请求过程中编辑会取消对应请求；请求身份、原文字、工程和选区上下文共同防止迟到响应覆盖新修改。编辑和生成沿用项目的撤回与历史版本恢复机制。
- 当前选区位于单个可编辑段落或片段内，不声称支持跨多个 textarea 的连续原生选区；需要跨相邻段落操作时，可先合并再选择。

## 音频资产与用户定义的生成单位

点击“生成选区音频”会先把选区变成独立的人声时间线片段，再只提交选中的片段。选中整个片段时不额外拆分。长文引擎的内部生成组是另一层处理细节；界面将模式称为“长文连续生成”，在技术详情中明确标注“内部生成组”。

未涉及片段的已有音频继续保留。修改某段文字、拆分已有录音的整段或合并已有录音的片段，会清空涉及片段当前绑定的旧音频并标记为待生成。当前没有任意文字边界对应的可靠逐字音频对齐，按字数比例计算的只是待生成片段的临时时间，不冒充精确音频切点。新候选仍需用户主动采用。

涉及已有录音的编辑会先保留工程历史版本；撤回可恢复之前工程，完整原音和底层资产不删除。旧范围的迟到候选不能自动进入修改后的工程。工程输入暂时无效时，磁盘/浏览器中最后有效的工程不被无效输入覆盖。

## 等待与时间线行为

人声片段新增可选 `pause_after`，记录该段到下一人声片段之间的用户指定等待。新策划编译成工程时，也会把短/中/长规划等待写入该字段，使真实生成时长变化后仍保留规划等待。没有该字段的旧已存工程沿用已有行为。已有音频时，编辑器按实际音频时长计算等待；生成前暂用规划时长。

用户定义的片段收到音频后，时间线时长跟随真实音频。无论新音频变长还是变短，后续时间都相应移动，使下一段从 `片段开始 + 实际音频时长 + pause_after` 开始。这样语音变长不会吃掉等待，变短也不会多出未指定的空白。调整等待复用已有音频，不触发新的 TTS。

时间移动只调整后续提示点，不裁剪其音频。非循环片段保留完整时长；循环环境声和情绪区间按需要调整覆盖范围。拆分后的内部等待初始为零，原来的段后等待交给最后一个新片段，用户随后可以逐处修改。工程总边界会适配保留下来的素材。

## 工作区布局

- 工程页上方左侧是文本编辑，右侧是声音与生成，两块各自内部滚动；时间线放在下方整行，情绪和工程检查折叠在其后。
- 左侧直接编辑台词，包含选区改写/生成、拆合增删、等待和撤回。选择时间线片段时，同步选择对应文本卡片。
- 右侧用简短“当前范围”摘要代替第二个 textarea。参考声音、生成/取消、候选试听/采用优先；当前人声和完整原音仍可访问。原音历史默认折叠，生成期间有可用原音时展开一次，任务结束不收起用户正在试听的内容。
- 保留距离、移动、音量与声像等空间主控，包括定距环绕和环绕靠近。时间微调、表演快捷、引擎设置和技术来源按需展开；折叠字段校验失败时展示对应错误。
- 项目详情栏默认收起，展开后提供整段试听、导出、历史和元数据。候选撤回、原音下载及播放控件均保留。
