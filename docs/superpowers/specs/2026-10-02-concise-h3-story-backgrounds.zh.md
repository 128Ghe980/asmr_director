# 精简 H3 提示词与面向人的剧情背景

日期：2026-10-02

状态：**实现、自动检查、真实文字模型及正式浏览器验证完成**。本项优化既有音质 V1 逐段分镜流程，不新增顶层阶段。[English spec](2026-10-02-concise-h3-story-backgrounds.md)

## 决定与官方范围

用户反馈背景、前镜和声音说明反复出现，prompt 过长。剧情背景应是供人查看的简短中文，例如「雪地中的木屋内」；模型据此为当前片段派生壁炉、窗边或窗外雪景等具体画面，不将背景全文粘贴进每段导出 prompt。

官方完整 Ref 改写格式确实包含 `summary`，用于简短汇总任务及参考关系；这不等于已经证明每个产品入口都做必填技术校验。本轮按用户要求采用精简自定义产品模板，不宣称严格复现官方完整改写结构。[MiniMaxAI 官方 Ref 指南](https://huggingface.co/MiniMaxAI/MiniMax-H3/blob/main/docs/VIDEO_PROMPT_WRITING_GUIDE_ref_en.md)

用户提供的官方手册第四节按素材用途、核心创意与可见画面过程组织高层输入。它与完整 Ref 扩写输出指南用途不同；本轮据此组织精简产品输入，不把两种格式说成同一规范。[H3 手册第四节](https://vrfi1sk8a0.feishu.cn/wiki/FIWjwgL33ipnkekzk30crmKUnIh)

## 行为

- Planner 与工程检查面板将现有 `sceneDescription` 字段显示为**剧情背景**。新模型结果为简短中文地点 / 氛围说明，供人查看及编辑，上限 160 字符；旧存储与手动编辑仍允许 4,000 字符。不在这里逐镜规划或推测参考角色外貌；每段画面 / 动作 / 镜头仍由模型输出英文。
- 背景与可选前镜上下文传给文字模型，让它派生本段具体说明；它们不是格式器参数，不再以 `Shared setting` 或前镜画面 / 动作 / 镜头块机械附加到导出 prompt。
- 共用 renderer 同时供旧 Planner H3 helper 与已采用片段 helper 使用。导出保留短角色 / 参考定义及保留规则、独立 `[Shot 1]`、当前画面 / 动作 / 镜头、一次逐字台词与嘴部规则以及 `non_diegetic_music: N/A`；移除 `summary` 和完整六段标题包装、重复背景 / 前镜文本及多处重复声音段落。
- 角色外貌仍以 `<Picture 1>` 为准，忽略推测细节；`<Audio 1>` 仍 `fully_copy` 完整不变的最终音轨，不新增声音或配乐。当前工程台词逐字注入，片段 prompt 保留真实实测音频时长。

既有请求与数据关联保留：新镜默认独立，可选只参考相邻前一条有效完整人声分镜。模型仍收到前镜参考，前镜内容仍参与过期依赖；从最终 prompt 删除前镜全文不代表移除其生成影响或依赖关系。

旧英文背景、手改分镜、音频编号 / 时长及前镜 metadata 均保留，不在刷新时自动翻译、覆盖或重生成。可选 Project JSON schema、来源校验、过期 / 暂空说明可编辑、复制 / 下载门控、取消、声音撤回与视频不影响声音指纹等既有行为保持。语言与创意要求由模型提示表达，schema 验证不代表艺术效果验收。
