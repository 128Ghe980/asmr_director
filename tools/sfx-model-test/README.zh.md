# 本地模型 SFX 实验

这套独立工具测试贴耳护理声音能否分别生成，以及波形是否存在重复。
不会自动采用进主工作台。见 [English](README.md)。

- 模型为官方 `cvssp/audioldm2`，固定 revision
  `c8e7e189d324425c05c4c2f81214041ef4107983`。
- 权重许可 CC-BY-NC-SA-4.0，本轮仅作独立非商用实验。输出 16kHz 单声道；
  不宣称双耳录音、贴耳空间处理或音质已通过。
- CUDA / Diffusers、FP16、CPU offload、默认 PyTorch SDPA、DPM multistep、
  50 步、guidance 3.5，每次只生成一条。实际依赖版本和显存写入 manifest。
- 刷耳、按摩、棉签清洁、喷雾，每类固定三个 seed，各独立生成 8 秒。
  本机补刷耳和按摩各三个种子的长段，用于检查连续变化。
- Stable Audio 3 Small-SFX 留作后续比较，其官方下载要求账号持有者先接受门禁协议。

权重、环境、缓存、音频和报告都留在 Git 外的 I 盘。只读复用已有 CUDA 环境，
不安装或修改其中的依赖。外部下载凭据记录官方 revision、字节数和 SHA256；
只下载配置、tokenizer、safetensors，避免重复 `.bin`。来源见
`docs/THIRD_PARTY_RUNTIMES.md`。完整 PowerShell 命令见英文说明。

工具核对提示词和原声 SHA256 后保留成功的 run ID，拒绝覆盖已有原始文件。
更改提示词需新建实验目录。主动重试时，旧失败记录留在 manifest 的 attemptHistory。
长音从新随机噪声直接生成，没有短片段循环或拼接。原始 float32 WAV 不改；
试听工具另复制不变的原声和仅调增益的试听副本，显示实际增益。
没有降噪、淡入淡出、裁剪或空间处理。

PCM 哈希用于发现完全相同音频；活跃、不重叠窗口用于筛查近乎相同的波形，
RMS 包络自相关用于提示周期性。报告注明覆盖范围与阈值。不同 seed、哈希或
低相关不能证明自然、好听或动作准确；新候选最初会标为听感待确认，但现有三条
远端刷耳已于 2026-10-05 全部拒绝。原定试听关注动作
辨识、刺耳感、意外人声或音乐、三个版本差异、长段是否听到同一摩擦反复出现。
真实录音参考页仍在 8768 端口。

## 分开的远端公开演示

`generate_remote.py` 使用 HF 团队的公开 AudioLDM2 演示，实际为 200 步 DDIM。
请求时间包含排队、网络和下载，显存未测，加载的权重 revision 未披露。
保存源码版本及每个 API job/SSE 凭据；与固定版本的本机基线分目录。
公开演示时长限制 5–15 秒。

不再提交任务。保存的 remote manifest 保留历史生成元数据；2026-10-05 的拒绝
结论已覆盖最初 pending 状态。
